# AI-Powered Customer Support Ticket Classification & Routing

## Overview
An independent machine learning project to classify banking
customer queries into intent categories and recommend appropriate
support-team routing.

## Dataset
BANKING77 — public banking customer-query intent dataset.

## Planned Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Natural Language Processing
- FastAPI
- Streamlit
- Git and GitHub
